# Проверки без LLM

Запустите из корня проекта:

```
uv run .doc-kit/doc-gates/tools/check.py --root .
```

Результат записывается в `_quality/check-report.yaml`. Код выхода 1 означает блокирующие замечания.

Сначала исправляйте блокеры. Пока они есть, LLM-гейты не запускаются. Предупреждения G08 показывают, какие истории стоит отдать в LLM-проверку.
