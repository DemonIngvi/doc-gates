# Проверки без LLM

Запустите из корня проекта:

```
uv run .doc-kit/doc-gates/tools/check.py --root .
```

Результат записывается в `_quality/check-report.yaml`, там же процент готовности с потолком при блокерах. Код выхода 1 означает блокирующие замечания.

Сначала исправляйте блокеры. Пока они есть, LLM-гейты не запускаются. Предупреждения G08 по эпикам это подсказка по словам: они говорят, что класс не упомянут, а не что сценарий плох.

В файле истории каждая строка таблицы случаев начинается с класса: `S3 Нет Process`. Классы без строки перечисляются в строке `**Not applicable:** S6 — своя причина; S7, S8 — своя причина`. Отписка вроде «не применимо» блокируется.
