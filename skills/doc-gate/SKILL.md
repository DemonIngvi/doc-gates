# LLM-проверка

Только после зелёного `doc-check`. Запускается скриптом, а не агентом: обычный агент добавляет около 32 тысяч токенов.

```
uv run .doc-kit/doc-gates/tools/run_gate.py G11 --root . --author "<кто писал>"
uv run .doc-kit/doc-gates/tools/run_gate.py G01 --root . --target <файл истории> --author "<кто писал>"
```

## Правила

- Результат лежит в `_quality/<гейт>/`, расход в `_quality/cost-log.yaml`.
- Покажите человеку блокеры. Находки не применяются автоматически: человек ставит `decision` и `decided_by`.
- Вердикт `pass` закрывает ворота только с подписью человека.
- Один запуск не доказывает полноту: в замере даже известный блокер находился не в каждом запуске.
- Код выхода 3 значит, что расход превысил оценку вдвое. Остановитесь и найдите причину.
