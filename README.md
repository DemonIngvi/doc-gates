# doc-gates

Проверки документации, совместимые с BMad Method. Сначала скрипты, затем LLM, затем человек.

| Проверка | Способ | Что делает |
| --- | --- | --- |
| G03 | Скрипт | Форма истории: разделы, заглушки, ссылки на FR |
| G05 | Скрипт | Запрещённые синонимы из `docs/terms-reject.txt` |
| G07 | Скрипт | Трассировка FR и NFR |
| G08 | Скрипт, затем LLM | Фильтр размытых критериев и негативных сценариев |
| G12 | Скрипт | Допущения в тексте совпадают с индексом |
| G01 | LLM | Незаписанные решения в истории |
| G11 | LLM | Независимый вердикт по плану |

## Запуск

```
uv run tools/check.py --root <проект>
uv run tools/run_gate.py G01 --root <проект> --target <файл истории>
```

`run_gate.py` не запускает LLM при красных скриптах и неизменившемся входе, проверяет дословность цитат, отклоняет шаблонные ответы, ведёт журнал расхода и останавливается при превышении оценки вдвое. Обход для калибровки: `--force`.

Если `claude` нет в `PATH`, укажите путь в `CLAUDE_BIN`. Для повторов служит `compare_runs.py`.

Правила и замеры находятся в [doc-rules](https://github.com/DemonIngvi/doc-rules).
